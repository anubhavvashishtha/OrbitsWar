# OrbitsWar RL Training — How to Run

## Prerequisites

```bash
pip install torch numpy
```

You also need the Kaggle environment installed (already required for self-play):

```bash
pip install kaggle-environments
```

---

## Folder Structure

```
OrbitsWar/
├── main.py                  ← your agent (untouched)
├── value_fn.py              ← GBM classifier output (existing)
├── rl_value_fn.py           ← RL neural net output (generated by Phase 3)
│
├── classifier/
│   ├── train.py             ← 1v1 GBM self-play training
│   ├── ffa_train.py         ← 4P FFA GBM self-play training
│   └── train_from_replays.py← replay parser + feature extractor
│
├── rl/
│   ├── net.py               ← OrbitsNet architecture (30→128→64→1)
│   ├── buffer.py            ← RolloutBuffer with GAE
│   ├── replay_trainer.py    ← Phase 1: pretrain on Kaggle replays
│   ├── self_play_trainer.py ← Phase 2: TD self-play vs enemies
│   ├── export_weights.py    ← Phase 3: export model.pt → rl_value_fn.py
│   ├── ppo_agent.py         ← Full pipeline entry point (runs all 3 phases)
│   └── model.pt             ← saved checkpoint (created after training)
│
└── records/                 ← Kaggle replay JSON files (~1.8 GB)
```

---

## Quick Start — Full Pipeline

Run all three phases in one command:

```bash
python rl/ppo_agent.py
```

Default settings: 10 self-play rounds × 8 games each.

**Options:**

```bash
# Skip replay pretraining (use existing model.pt from a previous run)
python rl/ppo_agent.py --skip-replay

# Resume replay pretraining from existing checkpoint
python rl/ppo_agent.py --resume

# More self-play rounds for better convergence
python rl/ppo_agent.py --rounds 20 --games 12

# Only re-export weights (no training)
python rl/ppo_agent.py --export-only
```

## Step-by-Step (Run Each Phase Separately)

### Phase 1 — Pre-train on Kaggle Replays

Trains OrbitsNet on labeled game states from `records/` (win/loss from real competition games).

```bash
python rl/replay_trainer.py
```

- Reads replay JSON files from `records/` via `classifier/train_from_replays.py`
- Trains with BCE loss for 30 epochs (AdamW + cosine LR schedule)
- Saves best checkpoint to `rl/model.pt`
- Expected time: 5–15 minutes depending on record count

```bash
# Resume from existing checkpoint instead of starting fresh
python rl/replay_trainer.py --resume
```

> **Note**: Requires at least one `.json` replay file in `records/`. Run
> `python classifier/train_from_replays.py` first to verify the records parse correctly.

---

### Phase 2 — Self-Play Fine-Tuning

Fine-tunes the model by playing against enemy agents using TD(0) learning.

```bash
python rl/self_play_trainer.py
```

- Loads enemy agents from `enemy agents/*.py`
- Your agent (`main.py`) plays 8 games per round against random enemy combos
- Runs TD updates after each game: `V(s_t) ← γ·V(s_{t+1})` mid-game, `V(s_T) ← won` at terminal
- Saves checkpoint after each round to `rl/model.pt`
- Prints W/L/D and TD loss per round

```bash
# More rounds for stronger convergence
python rl/self_play_trainer.py --rounds 20 --games 12
```

> **Tip**: Start Phase 2 only after Phase 1 has run — the pretrained checkpoint gives
> a much better starting point than random weights.

---

### Phase 3 — Export Weights

Converts `rl/model.pt` into a pure-Python/numpy file that works on Kaggle without PyTorch.

```bash
python rl/export_weights.py
```

- Reads `rl/model.pt`
- Writes `rl_value_fn.py` at the project root
- The exported file has a numpy fast path and a pure-Python fallback (no dependencies)
- Interface: `NN_LOADED = True`, `nn_value_score(feats, turn) → float`

---

## Integrating rl_value_fn.py into main.py

After Phase 3 generates `rl_value_fn.py`, add these lines to `main.py` after the
existing `value_fn` imports:

```python
NN_LOADED = False
try:
    from rl_value_fn import NN_LOADED, nn_value_score
except ImportError:
    pass
```

Then blend the RL signal into `plan_moves` where the RL boost is computed:

```python
if NN_LOADED:
    nn_pw = nn_value_score(feats, world.step)
    rl_boost = 0.35 * (nn_pw - 0.5)
```

## How the Two Systems Relate

| | GBM Classifier (`value_fn.py`) | RL Neural Net (`rl_value_fn.py`) |
|---|---|---|
| **Training data** | Kaggle replays + self-play snapshots | Kaggle replays (Phase 1) + self-play games (Phase 2) |
| **Model** | 3× GradientBoostingClassifier ensembles | OrbitsNet: 30→128→64→1 with LayerNorm |
| **Update frequency** | After each training round | After each self-play game (TD step) |
| **Inference speed** | Fast (tree traversal) | Faster with numpy BLAS |
| **Strengths** | Stable, interpretable, works well from replays | Improves via RL, can learn timing/tempo |

Both systems use the same **30-dimensional feature vector** from `classifier/train_from_replays.py:extract_features()`.

You can run both in parallel: if `NN_LOADED` is True, the RL boost overrides the GBM weight.
If `rl_value_fn.py` is missing, the agent falls back to GBM silently.

---

## Recommended Training Schedule

1. Collect replays: `records/` should have 200+ JSON files for good coverage
2. Run Phase 1 once: `python rl/replay_trainer.py`
3. Run Phase 2 with 15–20 rounds: `python rl/self_play_trainer.py --rounds 20`
4. Export: `python rl/export_weights.py`
5. Test locally, then submit to Kaggle

For a subsequent training iteration (e.g. after collecting more replays):

```bash
python rl/ppo_agent.py --resume --rounds 15
```

## Troubleshooting

| Error | Fix |
|---|---|
| `No replay records found` | Run `python classifier/train_from_replays.py` to verify record parsing |
| `No enemy agents found` | Add `.py` agent files to `enemy agents/` folder |
| `No model.pt found` | Run Phase 1 first, or use `--skip-replay` to start Phase 2 from random weights |
| `Import error: torch` | Run `pip install torch` |
| `Import error: kaggle_environments` | Run `pip install kaggle-environments` |
